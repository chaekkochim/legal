# 책꽂힘 약관

책꽂힘 이용약관과 개인정보 처리방침입니다. 앱과 웹이 이 파일을 읽어 보여줍니다.

- [이용약관](terms.md)
- [개인정보 처리방침](privacy.md)
- [지난 약관](history) · [변경 내역](CHANGELOG.md)

## 개정

1. `next/`에 새 글을 올리고 `effective`에 시행일을 적습니다. 불리한 변경은 30일 전, 그 밖에는 7일 전에 올립니다.
2. 시행일에 `terms.md`/`privacy.md`로 옮기고 `history/`에도 남깁니다.
3. `CHANGELOG.md`에 한 줄 적습니다.

글은 제목(`##`), 문단, 목록(`-`)만 씁니다. 문의 메일 자리에는 `{{문의처}}`를 적습니다.
